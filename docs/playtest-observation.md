# 首关试玩观察表（不含通关路线）

Godot 4.7.1 → F5 → 开发区域 → 首关试玩。先不要阅读自动化通关路线，照自己的理解游玩；卡住也可以退出，不需要强行通关。

记录默认关闭，不影响正常试玩；需要复盘时自愿勾选“同意记录本次试玩”。记录仅保存在本机，主菜单回来后需要重新选择。不要在意见中填写姓名、联系方式等个人信息。

| 观察点 | 你的记录 |
|---|---|
| 你觉得玩家在控制什么？ | |
| 什么时候知道长按能打开轮盘？有没有以为操作没响应？ | |
| 能否分清二极管入口、出口和当前操作端点？ | |
| 如何判断装置已经激活、路径已经接通？ | |
| 有没有敌人在场却看不出弹丸是否有效？提示是否有帮助？ | |
| 达标后是否明白还需要清场？ | |
| 哪一步最卡、哪一句最难懂？ | |
| 主动退出/失败/完成，以及实际用时 | |

启用记录时，结算下方可打开报告目录，并填写“卡在哪里 / 哪里看不懂 / 其他意见”，也可以跳过。未完成就返回、重试或正常关闭，已经授权的记录也会结束保存；正式关卡完成状态、最佳利用率和解锁不受影响。

复盘时优先提供本局 summary.json 和你的观察。events.jsonl 是阶段、完成操作和每秒聚合战况，不包含完整输入流或弹丸轨迹。两者都不自动上传。

当前验证状态：自动化路线与规则测试不等于陌生玩家测试。你的无脚本试玩和之后的陌生玩家试玩仍需分别记录。
