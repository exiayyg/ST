# v0.6 视听观察表

从主菜单选择「首关试玩」，先不要查看通关脚本。试玩记录默认关闭；是否同意记录不影响游戏。建议先用低音量开始，通过主菜单／暂停菜单「视听设置」试听确认音，再调整至舒适音量。

| 观察项 | 记录 |
|---|---|
| 不看名字能否分辨加速器、质量器、反弹板、分流器？ | |
| 二极管入口、出口和当前选中端点是否清楚？ | |
| 能否分辨激活、有效命中、节点摧毁和达标声音？ | |
| 高频发射／命中是否刺耳、抢过预警或令人疲劳？ | |
| 菜单与 F2 在自己的分辨率下是否清楚、易点击？ | |
| 暂停时世界声音是否停止，继续后是否自然？ | |
| 减少动态效果后能否仍理解状态与方向？ | |
| 有无雾中敌人被声音／特效提前暴露的感觉？ | |
| 使用的耳机／扬声器、音量设置、实际试玩时长 | |
| 最希望修改的一处画面或声音 | |

这里只记录自愿反馈，无联网、录屏或原始按键采集。作者试听与陌生玩家教学验证是两项独立工作；自动化通关、波形校验和设备播放成功都不能代替它们。
